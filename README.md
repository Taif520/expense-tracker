# Expense Tracker — وين راحت المصاريف؟

A simple expense and income tracker built with HTML, CSS and JavaScript.

## About this project

This project was completed as part of a JavaScript workshop.

- The page structure (`index.html`), the design (`style.css`) and the initial data (`data.js`) were provided in the workshop.
- The JavaScript logic (`app.js`) , I studied it, tested it, and am using this project to practice JavaScript fundamentals.

## Features

- Display transactions with title, amount, category, date and type
- Automatic calculation of total income, total expenses and balance
- Add a new transaction (income or expense)
- Delete a transaction (with confirmation)
- Search transactions by title
- Data is saved in `localStorage`, so changes remain after refreshing the page
- Amounts are displayed in Omani Rial (OMR)

## Technologies

HTML, CSS, JavaScript, localStorage
